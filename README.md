# Shamraiz Ashraf — Personal Portfolio

A responsive, static personal portfolio website designed for GitHub Pages.

## Included
- Responsive dark navy and white design
- About, experience, skills, certifications, education and contact sections
- Professional portrait image slot
- CV download link
- Mobile navigation

## Before publishing

1. Add your professional photo at `assets/profile.jpg` (JPG format recommended).
2. Add your latest CV PDF at `assets/Shamraiz-Ashraf-CV.pdf`.
3. Review the content in `index.html`, especially job dates, title, location and contact details.
4. Confirm your public-sector email address is appropriate to publish publicly. If not, replace it with a personal professional email.

The page includes a graceful initials placeholder if `assets/profile.jpg` is not present. The CV link will work after you add the PDF.

## Publish using GitHub Pages

1. Create/sign in to a GitHub account with username `shamraizashraf`.
2. Create a **public** repository named exactly `shamraizashraf.github.io`.
3. Upload all files and folders in this package to the repository root (not the ZIP file itself).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, then click **Save**.
7. Wait for deployment. Your site should appear at `https://shamraizashraf.github.io/`.

GitHub Pages documentation: https://docs.github.com/en/pages/quickstart

## Custom domain
A custom `.com` domain is not normally free. If you later register a domain, add it in **Settings → Pages → Custom domain** and configure the DNS records required by GitHub Pages.
